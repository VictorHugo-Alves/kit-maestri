02 · Maestri

O maestro das suas IAs.

O Maestri é um aplicativo com uma tela infinita onde você coloca vários agentes de IA lado a lado, dá uma função para cada um, e eles conversam entre si.

Pensa numa orquestra

Cada IA é um músico que toca muito bem um instrumento. O Maestro lê a partitura, diz quem entra quando e garante que tudo soe como uma música só. No Maestri, o Maestro é uma IA também: você conversa com ele, e ele rege os outros.

O Maestri não é uma IA. É o palco. As IAs (Claude Code, Codex, Gemini, OpenCode) você instala e assina à parte, e escolhe quais quer no seu quadro.

Por que misturar IAs

🔀

Não depende de um só

Claude, ChatGPT e outros no mesmo quadro. Se um fornecedor cair ou mudar, a equipe continua.

🔍

Um revisa o outro

Modelos diferentes erram em lugares diferentes. Uma IA de outra empresa pega o erro que a primeira não vê.

⚖️

Rende mais a cota

Tarefa pesada vai para o modelo forte, tarefa simples para o leve. E cada assinatura tem a própria cota.

O que ele possibilita

01

Equipe com funções

Um lidera, um constrói, um confere, um pesquisa. Cada um faz uma coisa só, e faz melhor.

O Maestro manda tarefa, espera a resposta e revisa. Ou pede para o Codex revisar o código do Claude.

03

Banco, tela e pesquisa ao mesmo tempo. O que levaria uma tarde em fila sai em uma hora.

04

Notas compartilhadas

Um post-it no quadro ligado a vários agentes vira memória comum, mesmo entre IAs de empresas diferentes.

05

Um navegador dentro do quadro que o agente consegue ver e operar: clicar, preencher, conferir a tela que ele fez.

06

Uma cópia isolada do projeto para testar algo arriscado sem encostar no trabalho principal.

07

Rotinas

Comandos e lembretes agendados: todo dia às 9h, a cada 30 minutos, uma vez numa data.

08

Partituras

Salve a configuração da sua equipe e reaplique em outro projeto, sem montar do zero.

09

Local e privado

O quadro, as notas e os papéis ficam em arquivos na sua máquina. As IAs continuam falando com os servidores delas.

O vocabulário

TerminalUma mesa no quadro, onde roda uma IA.

PapelO texto que diz ao agente quem ele é, o que faz e o que não pode fazer.
PresetO tipo de IA que abre no terminal: Claude Code, Codex, OpenCode.

Na prática, é isto

Você não precisa decorar: quem digita é o Maestro. Mas é bom saber o que acontece por baixo.

# quem está no quadro?
maestri list
# criar um especialista com função e modelo fixos
maestri recruit "VH" --role "Dados e conferência" --command "claude --model sonnet"
# mandar tarefa e esperar a resposta
maestri ask "VH" "Confira os números da planilha de vendas e me diga o que não bate."
# mandar para dois ao mesmo tempo
maestri ask --batch '{"JP":"crie a tabela de clientes","Junior":"faça a tela de cadastro"}'
# atualizar o quadro que todos leem
maestri note write "Quadro" "FAZENDO: JP (tabela), Junior (tela)"

As regras que fazem funcionar

  1. Fale só com o Maestro.Ele distribui. Texto digitado na caixa de um agente não é seu, é do Maestro.
  2. Cada terminal tem uma função fechada.Com dois "executores" iguais, o Maestro não tinha critério e acabava fazendo tudo sozinho.
  3. Só o Maestro faz commit, push e publica.Cinco terminais mexendo no mesmo repositório é receita para conflito.
  4. O Maestro revisa tudo que volta.Roda o teste de novo. Não confia no "passou".
  5. Uma tarefa por agente por vez.A segunda espera na fila ou vai para outro.
  6. O Quadro é reescrito a cada etapa.FAZENDO, FEITO, ESPERANDO VOCÊ, BACKLOG. Bateu o olho, sabe como está.
  7. Modelo certo para cada tarefa.Pesado no Opus, volume no Sonnet, revisão cruzada no Codex.
04 · Obsidian

A memória que você enxerga.

O Obsidian é um aplicativo gratuito de notas. A diferença: as notas são arquivos de texto simples numa pasta do seu computador, e não ficam presas no sistema de outra empresa.

Por que isso importa para a IA

A IA lê e escreve esses mesmos arquivos. O que você anota, a IA sabe. O que a IA registra, você vê. Não existe "a memória da IA" escondida num lugar e "as suas notas" em outro: é uma pasta só.

📄 Notas em markdown: texto puro, abre em qualquer lugar
🔗 Links entre notas com [[nome]]
🕸️ Grafo: o mapa de como os assuntos se ligam
💸 Gratuito e sem conta obrigatória

O que ele possibilita

🪟

Uma janela para o cérebro

A IA trabalha dentro da pasta. Você olha e edita pelo Obsidian, com tudo organizado e pesquisável.

🧭

Contexto que não se perde

Decisões, regras do seu negócio e o que ficou pendente viram arquivos. A próxima conversa começa sabendo.

🧩

O segundo cérebro

Trabalho, estudos e projetos num lugar só, ligados entre si. Você e a IA pensando sobre a mesma base.

✳️
A regra de ouro: todo arquivo novo ganha uma linha no INDICE.md, e citar outro arquivo é sempre com link. É isso que faz o grafo funcionar e a IA achar as coisas.
05 · GitHub

O cofre com máquina do tempo.

O GitHub guarda a sua pasta de trabalho na nuvem, com o histórico de todas as versões. Cada vez que a IA salva um "ponto", dá para voltar a ele, ver o que mudou e quando.

☁️

Backup

O computador morreu, foi roubado, o disco corrompeu? Está tudo lá, do jeito que você deixou.

⏪

Máquina do tempo

A IA errou e apagou algo importante? Volta para a versão de ontem em segundos.

🔄

Sincronia

O que você fez no notebook aparece no computador do escritório. Essencial para quem usa mais de uma máquina.

Três palavras e você entende tudo

Setup inicialsegunda, 9h
Planilha de clientessegunda, 15h
Regras do negócioterça, 10h
Dashboard de vendasagora
COMMIT

Salvar um ponto

Uma foto da pasta naquele momento, com uma frase dizendo o que mudou.

PUSH

Enviar para a nuvem

Manda os pontos salvos do seu computador para o GitHub.

PULL

Trazer da nuvem

Puxa o que foi feito no outro computador antes de começar a mexer.

🤖
Você não precisa aprender git. A IA faz commit e push ao fim de cada tarefa, e pull ao começar. Você só olha o histórico quando quiser.

E o tal do token?

Para o seu computador poder enviar arquivos para o seu GitHub, ele precisa de uma chave de acesso, que o GitHub chama de token. É como uma senha só para isso, que você cancela quando quiser.

O JEITO CERTO

Login pelo navegador

Num terminal separado, você digita gh auth login e autoriza no navegador. O próprio GitHub gera e guarda a chave. Ela nunca aparece na conversa com a IA.

NUNCA

Colar token no chat

Tudo o que você manda para a IA vai para o servidor dela. Token, senha e chave ficam fora da conversa, sempre.

🔒
Repositório privado. Se tem dado do seu negócio, o repositório é privado. Só você (e quem você convidar) enxerga.
06 · Juntando tudo

Uma pasta, três papéis.

O segredo é que as três ferramentas olham para a mesma pasta. Ela é, ao mesmo tempo, o workspace do Maestri, o cofre do Obsidian e o repositório do GitHub.

Um dia de trabalho

MANHÃ

Você pede

"Monta o relatório de vendas da semana e confere com a planilha."

MAESTRI

A equipe faz

O Maestro divide: um lê os dados, outro monta, outro confere. Ele revisa.

OBSIDIAN

Fica registrado

O relatório e a decisão do dia viram arquivos, ligados no índice.

GITHUB

Fica guardado

Commit e push. À noite, no outro computador, está tudo lá.

Um .zip com o roteiro para a IA, o guia completo do Maestri, modelos e a cola de comandos.

Instale o Maestri e uma IA

O Maestri em themaestri.app. E pelo menos uma IA de terminal, já logada na sua conta:

# Claude Code · Mac e Linux
curl -fsSL https://claude.ai/install.sh | bash
# Claude Code · Windows (PowerShell)
irm https://claude.ai/install.ps1 | iex
# Codex · qualquer sistema com Node.js
npm install -g @openai/codex

Crie a pasta do seu cérebro

Uma pasta vazia, por exemplo Documentos/meu-cerebro. Descompacte o kit dentro dela. No Maestri, crie um workspace apontando para essa pasta e abra um terminal com a sua IA.
